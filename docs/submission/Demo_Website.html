How accurately does the agent work?

Every scenario run is scored by Python against the database's own answer (issue, cause, actions) and checked for invented facts. Run with python -m scagent scenarios --repeat 2. It isn't started from this page because it makes many paid model calls.

A model can sound confident and still be wrong. After every run, Python checks:

  • each ID and date in the report came from a tool result,
  • the issue and cause are backed by evidence the model actually saw,
  • each recommended action has the data it depends on,
  • a failure isn't reported as success,
  • the issue, cause and actions match the database's own answer.
